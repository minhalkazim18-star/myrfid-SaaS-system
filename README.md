# 🚀 MyRFID SaaS System (Digital Attendance & Management System)

<a name="readme-top"></a>

## 📌 About The Project
A comprehensive digital RFID attendance and management SaaS system built for tracking student or staff attendance securely and efficiently. This project helps eliminate manual attendance logging and provides automated reporting for administrators.

---

## 🛠️ Built With
* **Language:** Native PHP, JavaScript
* **Database:** MySQL
* **Styling & UI:** Bootstrap / Tailwind CSS
* **Libraries / Tools:** PHPMailer, FPDF (for report generation)

---

## ✨ Key Features
* **RFID Attendance Scanning:** Real-time attendance logging via RFID hardware/kiosk interface (`kiosk.php`).
* **Superadmin & Role Management:** Multi-tier user roles (Superadmin, Admin, Guru/Staff, Pelajar) with secure session authentication.
* **Automated Reporting:** Generate and export PDF attendance reports and logs instantly.
* **Activity & Audit Logs:** Track system activities and user login histories for enhanced security.
* **Email Notifications:** Integrated automated email alerts using PHPMailer.
